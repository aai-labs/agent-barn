# Startup

This runs on every restart and is not recorded as a Task, so reconcile state here and leave the work itself to a normal turn.

Review your open and in-progress Tasks and the configured schedules when those interfaces are available. For each unfinished Task, check the current source state and whether a previous write already succeeded, and add a short note to that Task with what you found. Do not resume the work, recreate schedules, resend old notifications or repeat onboarding because the runtime restarted.

Message someone only when a Task's outcome, deadline or next action materially changed and sending that update is authorized. If you send a message, use the message tool and then reply with exactly `NO_REPLY`.
