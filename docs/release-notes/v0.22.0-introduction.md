## What you can do now

Agent Barn v0.22.0 adds file handling for workflows, scheduled Agent restore
points, and GitLab integration. It also fixes Hermes Slack channel and DM
authorization and validates integration credentials before stopping a running Agent.

- **Pass files into and out of workflows.** Workflow files use Agent artifacts,
  and sharing can reuse an already-published artifact.
  [Workflow file support](https://github.com/aai-labs/agent-barn/pull/346) ·
  [Artifact reuse](https://github.com/aai-labs/agent-barn/pull/354).
- **Keep a rolling window of scheduled restore points for running Agents.**
  [Restore-point change](https://github.com/aai-labs/agent-barn/pull/339).
- **Connect GitLab through the integration system.**
  [GitLab integration](https://github.com/aai-labs/agent-barn/pull/357).
- **Update credentials with validation before interruption.** Invalid credentials
  are checked before stopping the running Agent for the change.
  [Credential validation](https://github.com/aai-labs/agent-barn/pull/356).

These describe changes included in the release's published PR list, not a claim
that every deployment or external workflow has been verified end to end.

## Before upgrading

Read the [operations guide at v0.22.0](https://github.com/aai-labs/agent-barn/blob/v0.22.0/docs/guidelines/operations.md)
and compare your configuration with the
[deployment specification at that tag](https://github.com/aai-labs/agent-barn/blob/v0.22.0/.env.deploy.spec).
Review required storage, migrations, runtime image versions, backup and recovery
steps for your deployment. A maintainer must complete the deployment-specific
upgrade check before publishing this introduction; this draft is not an upgrade
runbook or a statement that upgrading is risk-free.

Preserve the existing **What's Changed** list, author attribution, and
[full changelog](https://github.com/aai-labs/agent-barn/compare/v0.21.0...v0.22.0)
below this introduction. Select **Watch → Custom → Releases** on the repository
to receive future release notifications.
